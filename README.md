# Prompt Log

**생성한 이미지·영상과 그걸 만든 프롬프트를 한곳에 모아두는 로컬 갤러리.**

ComfyUI로 뽑은 PNG는 **프롬프트·모델·시드가 파일 안에 이미 박혀 있습니다.** Prompt Log는 그걸
읽어서 자동으로 채웁니다. 손으로 적는 건 태그나 메모 정도고, 나머지는 폴더만 지정하면 끝입니다.

- 회원가입이나 외부 서버가 필요 없습니다. 일반 사용자는 **Windows 설치 파일 하나**로 설치할 수 있습니다
- 서버로 아무것도 보내지 않습니다. 전부 내 컴퓨터 안에서 돕니다
- 기록은 결과물 폴더 안에 같이 남아서, 폴더를 옮기면 기록도 따라갑니다

---

## 웹에서 바로 실행

**[Prompt Log 열기](https://prompt-log.juyurani.chatgpt.site/)**

Chrome 또는 Edge에서 링크를 열고 `📁 폴더 선택하기`를 누르면 됩니다. 웹 버전도 선택한 폴더를
브라우저에서 직접 읽고 쓰며, 이미지·프롬프트를 별도 서버로 전송하지 않습니다.

### 모바일에서 보기

모바일 브라우저에서는 `📱 폴더 통째로 보기`를 누르고 Prompt Log 라이브러리 폴더를 선택하세요.
검색, 이미지·영상 분류, 상세 보기, 프롬프트 복사를 사용할 수 있습니다. 모바일 보기 모드는 원본을
보호하기 위해 **읽기 전용**이며 저장·삭제·새 항목 추가는 제공하지 않습니다.

기기에서 폴더 선택을 지원하지 않으면 `파일 선택해서 보기`를 누르고 라이브러리의 `metadata.json`과
보고 싶은 이미지·영상 파일을 함께 선택하세요. 파일은 서버로 업로드되지 않고 현재 브라우저 탭에서만
열립니다.

## Windows에 설치하기 (일반 사용자)

### 1. 설치 파일 받기

GitHub Releases에서 최신 `PromptLog-Setup-x.y.z.exe`를 내려받습니다. 압축을 풀 필요는 없습니다.

> 공개 배포본은 게시자가 제공한 SHA-256 체크섬과 파일의 체크섬이 같은지 확인하는 것을 권장합니다.

### 2. 설치하기

1. 내려받은 `PromptLog-Setup-x.y.z.exe`를 더블클릭합니다.
2. 설치 언어를 선택합니다.
3. 설치 위치와 바탕 화면 바로가기 여부를 확인합니다.
4. **설치**를 누릅니다. 관리자 권한은 필요하지 않습니다.
5. 완료 화면에서 **Prompt Log 실행**을 선택하고 마칩니다.

서명되지 않은 개발 빌드에는 Windows SmartScreen의 "Windows의 PC 보호" 화면이 나올 수 있습니다.
공식 배포자는 코드 서명을 마친 파일만 배포해야 합니다. 개발 빌드를 직접 신뢰하고 실행하는 경우에만
`추가 정보` → `실행`을 선택하세요.

### 3. 처음 실행하기

1. Prompt Log가 기본 브라우저에서 자동으로 열립니다.
2. Chrome 또는 Edge가 아니라면 주소를 복사해 Chrome/Edge에서 여세요.
3. `📁 폴더 선택하기`를 누르고 이미지·영상 결과물 폴더를 선택합니다.
4. 브라우저의 읽기/쓰기 권한 요청을 확인하고 허용합니다.

앱을 닫으려면 브라우저 탭만 닫는 것이 아니라, 작업 표시줄 오른쪽 알림 영역의 Prompt Log 아이콘을
오른쪽 클릭한 뒤 **종료**를 누릅니다. 다시 열려면 시작 메뉴에서 **Prompt Log**를 실행합니다.

### 제거하기

Windows **설정 → 앱 → 설치된 앱 → Prompt Log → 제거**를 선택합니다. 앱을 제거해도 사용자가
선택했던 라이브러리 폴더의 원본과 `metadata.json`, `.thumbs`, `.refs`는 삭제하지 않습니다.

## 개발자용 빠른 시작

**1. 준비물** — Chrome 또는 Edge, 그리고 Python.

> Firefox와 Safari는 아직 안 됩니다. 폴더를 읽는 데 쓰는 브라우저 기능(File System
> Access API)을 지원하지 않습니다.

**2. 실행** — 받은 폴더에서 `run.bat`을 더블클릭하면 브라우저가 열립니다.

직접 하시려면 폴더에서 터미널을 열고:

```bash
python -m http.server 8765
```

그다음 브라우저에서 `http://localhost:8765/prompt-log.html` 로 접속합니다.

> **`prompt-log.html`을 그냥 더블클릭하면 안 됩니다.** 보안 제약 때문에 `file://` 로 열면
> 폴더 선택 버튼이 동작하지 않습니다. 반드시 `localhost` 로 접속해야 합니다.

**3. 폴더 지정** — `📁 폴더 선택하기` 를 누르고 결과물이 들어 있는 폴더를 고릅니다.
ComfyUI의 `output` 폴더를 그대로 지정해도 되고, 따로 정리해둔 폴더도 됩니다.
하위 폴더까지 알아서 훑습니다.

끝입니다. 카드가 바로 뜨고, 프롬프트는 뒤에서 하나씩 채워집니다.

### Windows 설치 파일 빌드

Windows에 포함된 .NET Framework C# 컴파일러와 Inno Setup 6를 사용합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\build.ps1
```

빌드 결과는 `dist\PromptLog-Setup-0.5.0.exe`입니다. Inno Setup이 없으면 호스트 EXE만
`build\windows\PromptLog.exe`에 만들어지고 설치 프로그램 빌드는 건너뜁니다.

공개 배포 전에는 반드시 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)를 확인하세요.

## 내 파일은 어떻게 되나요

먼저 알아두시는 게 좋습니다.

| | |
|---|---|
| 원본 파일을 열어서 **읽기만** 합니다 | 내용을 고치거나 옮기거나 이름을 바꾸지 않습니다 |
| 폴더 안에 파일 몇 개를 **새로 만듭니다** | `metadata.json`, `metadata.backup.json`, `.thumbs/`, `.refs/` |
| 인터넷으로 아무것도 보내지 않습니다 | 계정도 서버도 없습니다 |

**단 하나의 예외 — 항목 창의 `삭제` 버튼은 원본 파일까지 지웁니다.** 목록에서만 빼는 게
아니라 디스크에서 지워지고, 휴지통으로 가지 않습니다. 확인 창에 지워질 파일 이름이 나오니
꼭 보고 누르세요.

| 버튼 | 하는 일 |
|---|---|
| `↻ 새로고침` | 폴더에 새로 생긴 파일을 읽어옵니다. 생성 툴을 돌린 뒤 누르세요 |
| `✨ 자동 추출` | 프롬프트가 비어 있는 기존 항목에서 파일에 박힌 정보를 다시 찾습니다 |
| `🔗 input 폴더` | ComfyUI `input` 폴더를 연결해 참조 이미지를 자동으로 채웁니다 |
| `폴더 변경` | 다른 라이브러리 폴더로 바꿉니다 |
| `🌙 / ☀️` | 어두운 테마 / 밝은 테마 |

| 단축키 | |
|---|---|
| `/` | 검색창으로 이동 |
| `Esc` | 창 닫기 |

파일을 화면에 **끌어다 놓으면** 라이브러리에 추가됩니다.

## 프롬프트가 자동으로 채워지는 원리

ComfyUI는 PNG를 저장할 때 워크플로 전체를 파일 안에 넣습니다. A1111 계열도 설정을 텍스트로
남깁니다. Prompt Log는 그걸 읽어서 이만큼을 채웁니다:

**프롬프트 · 네거티브 · 모델 · 시드 · steps · cfg · 샘플러 · 스케줄러 · 해상도 · LoRA**

자동으로 채워진 카드에는 `AUTO` 배지가 붙습니다. **직접 입력한 값은 절대 덮어쓰지 않습니다** —
빈 칸만 채웁니다.

실측 정확도 (ComfyUI 출력 PNG 500장 무작위 표본): **프롬프트 98% · 모델 100% · 시드 94%**

안 되는 경우도 알아두세요:

- **영상(mp4 등)은 자동 추출이 안 됩니다.** 표준 규격이 없어서 파일에 프롬프트가 안 들어갑니다.
  Kling·Hailuo·Seedance 결과물은 프롬프트를 직접 붙여넣으셔야 합니다
- 웹에서 받은 이미지는 보통 메타데이터가 지워져 있습니다
- 업스케일만 한 이미지처럼 프롬프트가 원래 없는 경우도 있습니다

프롬프트가 비어 있으면 카드에 `정보 필요` 배지가 붙어서 눈에 띕니다.

카드를 누르면 창이 열립니다. 프롬프트·네거티브·툴·시드·모델·태그·메모를 넣고 `저장`.

- 여러 개를 한 번에 넣으면 저장할 때마다 다음 항목으로 넘어갑니다

## 참조 이미지·영상·오디오

img2img나 멀티모달 생성처럼 **입력을 넣어서 만든 결과물**은, 무엇을 보고 만들었는지도 같이
붙여둘 수 있습니다. 항목 창의 `참조 이미지` 칸에 파일을 끌어다 놓거나 `＋ 추가`로 고르세요.

- **이미지** — 누르면 확대해서 봅니다
- **영상** — 첫 장면과 길이(`0:03`)가 보이고, 누르면 재생창이 열립니다
- **오디오** — `♪` 와 길이(`0:13`)로 표시되고, **누르면 그 자리에서 재생**됩니다

Seedance·Kling·Hailuo처럼 영상이나 음성을 조건으로 넣는 모델을 쓸 때 유용합니다.
카드에는 `🖼🎬♪ 2/3` 처럼 종류와 개수가 표시됩니다.

### 빈 자리가 미리 만들어져 있다면

ComfyUI에서 `LoadImage`로 이미지를 넣었다면, **어떤 파일을 썼는지 이름이 파일에 남아 있습니다.**
Prompt Log는 그 이름으로 빈 자리를 미리 만들어 둡니다. 그 자리에 실제 파일을 끌어다 놓으면
이름은 그대로 두고 그림만 채워집니다.

더 편한 방법은 `🔗 input 폴더` 를 눌러 ComfyUI의 `input` 폴더를 한 번 연결해두는 겁니다.
**빈 자리가 알아서 채워집니다.** (실측: 참조 이름 54개 중 52개를 `input` 폴더에서 찾았습니다.)

> 브라우저 보안 정책상 창을 새로 열 때마다 이 버튼을 한 번 눌러 접근을 다시 허용해야 합니다.
> 허용이 필요한 상태면 버튼이 🔒 로 보입니다.

## 다른 사람에게 보여주기 — 내보내기

`⤓ 내보내기` 를 누르면 **지금 화면에 보이는 목록**(검색·필터 적용된 상태 그대로)이 HTML
파일 하나로 나옵니다.

- 인터넷도 서버도 필요 없습니다. **더블클릭하면 그냥 열립니다**
- 프롬프트·태그·썸네일·참조가 전부 파일 안에 들어 있습니다
- 카톡이나 메일로 보내면 받은 사람이 바로 봅니다

원본 파일을 포함할지 물어봅니다. **취소(썸네일만)** 를 고르면 가볍고, **확인(원본 포함)** 을
고르면 원본 화질로 보이지만 용량이 커집니다.

> 내보낸 파일은 그 시점의 **사진 한 장**입니다. 이후 라이브러리를 고쳐도 반영되지 않으니
> 다시 내보내야 합니다.

## 알아두면 좋은 것

**두 곳에서 동시에 열지 마세요.** 창 두 개나 컴퓨터 두 대에서 같은 폴더를 동시에 열면
기록 파일을 서로 덮어써서 한쪽 작업이 날아갑니다. (백업이 있어 복구는 되지만 번거롭습니다.)

**처음 대량으로 읽을 때는 탭을 앞에 두세요.** 브라우저가 백그라운드 탭에서는 썸네일 만드는
속도를 초당 1장 수준으로 줄여버립니다. 수천 장이면 차이가 큽니다.

**폴더를 옮겼다면** `폴더 변경` 으로 새 위치를 다시 고르면 됩니다. 기록이 폴더 안에 같이
들어 있어서 그대로 이어집니다.

**파일을 정리해도 기록이 끊기지 않습니다.** 앱 밖에서 파일을 다른 폴더로 옮기거나 이름을
바꿔도, 다음 `↻ 새로고침` 때 같은 파일로 알아보고 경로만 바꿉니다. 태그·메모·즐겨찾기가
그대로 따라갑니다. (이름과 수정시각이 **둘 다** 바뀌면 못 알아보고 새 항목이 됩니다.)

**파일을 지웠다면** 카드에 `파일 없음` 배지가 붙습니다. 적어둔 프롬프트는 지우지 않으니
기록은 남습니다.

**클라우드 폴더에 두실 거면** 해당 폴더를 "항상 이 장치에 유지"로 설정하세요. OneDrive의
파일 온디맨드처럼 실제 파일이 클라우드에만 있으면 스캔이 매우 느려지거나 실패합니다.

## 저장되는 파일과 복구

라이브러리 폴더 안에 이렇게 생깁니다:

```
내-폴더\
├─ metadata.json          ← 프롬프트·태그·메모 (이게 본체)
├─ metadata.backup.json   ← 직전 정상본 (자동)
├─ .thumbs\               ← 썸네일
├─ .refs\                 ← 참조 파일
└─ (원본 이미지·영상들)
```

`metadata.json` 이 깨지면 앱이 **덮어쓰지 않고 멈춥니다.** 깨진 파일은
`metadata.corrupt-날짜.json` 으로 따로 보관되고, 화면에 복구 방법이 안내됩니다 —
`metadata.backup.json` 의 이름을 `metadata.json` 으로 바꾸면 됩니다.

백업하시려면 **폴더째 복사**하면 됩니다. 그게 전부입니다.

- 수천 장을 넘어가면 검색·필터할 때 화면이 무거워집니다
- 파일 이름과 수정시각이 동시에 바뀌면 옮긴 파일로 알아보지 못합니다
- 링크 하나로 외부에 공개하는 기능은 없습니다 (`내보내기`로 대신합니다)
- Firefox·Safari에서는 폴더 읽기·쓰기 모드를 사용할 수 없습니다. 모바일에서는 읽기 전용 보기 모드를 사용하세요

### 프롬프트 추출

ComfyUI는 PNG의 `tEXt` 청크에 API 그래프(`prompt`)와 에디터 그래프(`workflow`)를 넣고,
A1111은 `parameters`에 평문을 넣습니다.

그래프 파싱은 "첫 번째 `CLIPTextEncode`를 집는" 방식이 아닙니다. 샘플러 노드의
`positive`/`negative` 링크를 거꾸로 타고 올라가 실제 텍스트를 찾습니다. 그래서:

- 포지티브와 네거티브가 뒤바뀌지 않습니다
- `ConditioningZeroOut`으로 비운 네거티브는 비어 있는 것으로 봅니다
- `Seed (rgthree)`처럼 시드를 링크로 넘기는 노드도 값을 따라갑니다
- `ImpactWildcardProcessor`는 전개된 결과(`populated_text`)를 원본 템플릿보다 우선합니다
- `StringConcatenate`로 조립한 프롬프트는 이어붙여 복원합니다
- 샘플러가 없는 그래프(업스케일 등)는 가장 긴 문자열로 대체하되 표시 전용 노드는 제외합니다

### 스캔

폴더를 최대 8단계까지 재귀로 훑습니다(`.`으로 시작하는 폴더 제외). 항목의 키는 폴더 기준
상대 경로라 같은 파일명이 여러 폴더에 있어도 충돌하지 않습니다.

스캔은 두 단계입니다. 목록만 읽어 항목을 전부 등록하고(즉시 끝남), 파일을 하나씩 열어야 하는
썸네일·메타데이터는 뒤에서 이어서 처리합니다. 그래서 수천 장짜리 폴더도 갤러리가 바로 뜹니다.
중간에 창을 닫아도 다음 실행에서 남은 것부터 재개합니다.

### 저장

썸네일은 `metadata.json`에 base64로 넣지 않고 `.thumbs/<id>.jpg` 파일로 뺍니다. 항목당 약
300바이트가 되어 7,500장 기준 `metadata.json`이 약 2MB에 머뭅니다(JSON에 넣으면 수백 MB).
화면에 보이는 카드만 썸네일을 읽습니다.

저장은 임시 파일에 쓴 뒤 교체하고, 동시 저장은 직렬화되어 섞이지 않습니다.

### 옮긴 파일 알아보기

파일 내용을 읽지 않고 **바이트 크기**에 아래 둘 중 하나가 맞을 때만 같은 파일로 봅니다.
어차피 여는 핸들에서 공짜로 나오는 값이라 추가 비용이 없습니다.

- **크기 + 수정시각** — 폴더째 드래그해서 옮긴 경우 (이름이 바뀌어도 잡힘)
- **크기 + 파일명** — 복사 후 삭제처럼 수정시각이 초기화된 경우

크기만 같은 건 근거로 치지 않고, 후보가 둘 이상이면 애매하다고 보고 건드리지 않습니다.
