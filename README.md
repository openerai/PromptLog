# Prompt Log

이미지·영상 생성 결과와 그걸 만든 프롬프트를 한곳에 모아두는 **의존성 없는 단일 HTML 갤러리**.
폴더 하나를 지정하면 하위 폴더까지 훑어 결과물을 읽어들이고, 메타데이터는 같은 폴더의
`metadata.json`, 썸네일은 `.thumbs/`에 남습니다. 서버도 빌드도 계정도 없습니다.

## 실행

File System Access API가 필요하므로 **Chrome / Edge**에서 `http://localhost`로 열어야 합니다
(`file://`에서는 폴더 선택이 동작하지 않습니다).

```bash
python -m http.server 8765 --directory .
```

그 후 `http://localhost:8765/prompt-log.html`.

## 프롬프트 자동 추출

ComfyUI는 PNG의 tEXt 청크에 API 그래프 전체(`prompt`)와 에디터 그래프(`workflow`)를 박아서 저장하고,
A1111 계열은 `parameters`에 평문으로 남깁니다. Prompt Log는 파일을 읽어들일 때 이걸 파싱해서
**프롬프트 · 네거티브 · 모델 · 시드 · steps · cfg · 샘플러 · 스케줄러 · 해상도 · LoRA** 를 자동으로 채웁니다.

ComfyUI 그래프는 단순히 "첫 번째 CLIPTextEncode"를 집지 않고, 샘플러 노드의 `positive` / `negative`
링크를 거꾸로 타고 올라가 실제 텍스트를 찾습니다. 그래서:

- 포지티브와 네거티브가 뒤바뀌지 않습니다
- `ConditioningZeroOut`으로 비워둔 네거티브는 비어 있는 것으로 인식합니다
- `Seed (rgthree)` 처럼 시드를 링크로 넘기는 노드도 값을 따라갑니다
- `ImpactWildcardProcessor`의 `populated_text`(전개된 결과)를 원본 템플릿보다 우선합니다
- `StringConcatenate`로 조립한 프롬프트는 이어붙여 복원합니다
- 샘플러가 없는 그래프(업스케일 등)는 가장 긴 리터럴 문자열로 대체하되,
  `easy showAnything` 같은 표시 전용 노드는 제외합니다

실측: 로컬 ComfyUI 출력 PNG 500장 무작위 표본 기준 — 프롬프트 98%, 모델 100%, 시드 94%.

자동으로 채워진 항목에는 `AUTO` 배지가 붙고, **자동 추출** 버튼으로 기존 항목도 소급 적용됩니다.
이미 입력된 값은 절대 덮어쓰지 않습니다.

영상(mp4 등)에는 표준 메타데이터가 없어 자동 추출 대상이 아닙니다.

## 스캔과 저장 구조

지정한 폴더를 **하위 폴더까지 재귀로** 훑습니다(최대 8단계, `.`으로 시작하는 폴더는 제외).
ComfyUI처럼 날짜별 폴더에 저장하는 도구도 그대로 잡힙니다. 항목의 키는 폴더 기준 상대 경로라
같은 파일명이 여러 폴더에 있어도 충돌하지 않고, 예전에 만든 최상위 항목도 그대로 열립니다.

스캔은 두 단계로 나뉩니다. 폴더 목록을 읽어 항목을 먼저 전부 등록하고(즉시 끝남),
파일을 하나씩 열어야 하는 썸네일 생성과 메타데이터 추출은 뒤에서 이어서 돕니다.
그래서 수천 장짜리 폴더를 처음 붙여도 갤러리는 바로 쓸 수 있고, 카드는 처리되는 대로 채워집니다.
중간에 창을 닫아도 다음 실행에서 남은 것부터 이어서 처리합니다.

썸네일은 `metadata.json` 안에 base64로 넣지 않고 `.thumbs/<id>.jpg` 파일로 저장합니다.
항목당 약 300바이트가 되어, 7,500장 라이브러리 기준 `metadata.json`이 약 2MB에 머뭅니다
(같은 썸네일을 JSON에 넣으면 수백 MB가 됩니다). 화면에 보이는 카드만 썸네일을 읽습니다.

폴더에서 사라진 파일은 다음 스캔 때 `파일 없음`으로 표시되고, 기록해둔 프롬프트는 지우지 않습니다.

## 파일을 옮기거나 이름을 바꿨을 때

앱 밖에서 파일을 정리해도 기록이 끊기지 않습니다. 스캔은 "사라진 항목 하나 + 새로 생긴 파일
하나"를 같은 파일로 인식해 **경로만 갈아끼웁니다.** 태그·메모·즐겨찾기·수기 프롬프트가 그대로
따라오고, 항목이 둘로 늘어나지 않으며, **썸네일도 다시 만들지 않습니다.**

판단은 파일 내용을 읽지 않고 **바이트 크기**에 아래 둘 중 하나가 맞아떨어질 때만 합니다.
어차피 열어야 하는 핸들에서 공짜로 나오는 정보라 추가 비용이 없습니다.

- **크기 + 수정시각** — 폴더째 드래그해서 옮긴 경우 (이름이 바뀌어도 잡힘)
- **크기 + 파일명** — 복사 후 삭제나 일부 동기화 도구처럼 수정시각이 초기화된 경우

크기만 같은 건 근거로 치지 않고, 후보가 둘 이상이면 애매하다고 보고 손대지 않습니다
(둘 다 `파일 없음`으로 남고 새 항목이 생깁니다). 이름과 수정시각이 **둘 다** 바뀌었거나
파일을 재인코딩한 경우도 새 항목이 됩니다.

> 첫 대량 임포트는 탭을 앞에 둔 채로 두세요. 브라우저가 백그라운드 탭에서는 JPEG 인코딩을
> 초당 1건 수준으로 제한합니다.

## 참조 이미지

img2img·이미지 편집이나 멀티모달 생성처럼 입력을 쓴 결과물은, 무엇을 보고 만들었는지를 항목에
붙여둘 수 있습니다. 항목을 열고 **참조 이미지** 칸에 파일을 끌어다 놓거나 `＋ 추가`로 고르면 됩니다.
파일은 `.refs/`에 보관되고, 카드에는 `🖼🎬♪ 2/3`처럼 (종류 / 첨부된 개수 / 전체 개수)가 표시됩니다.

**이미지·영상·오디오를 모두 받습니다.** Seedance·Kling·Hailuo처럼 영상이나 음성을 조건으로
넣는 모델을 쓸 때 그 입력도 그대로 기록됩니다.

- 이미지 — 썸네일로 보이고, 누르면 확대해서 봅니다
- 영상 — 첫 프레임을 정지컷으로 뽑아 `▶` 표시와 길이(`0:03`)를 함께 보여주고, 누르면 재생창이 열립니다
- 오디오 — `♪` 와 길이(`0:13`)로 표시되고, 누르면 **그 자리에서 바로 재생**됩니다
  (진행바가 차오르고, 다시 누르면 정지 · 다른 걸 누르면 앞의 것이 멈춥니다)

확대/재생창은 배경을 클릭하거나 `Esc` 로 닫습니다. 항목 창은 그대로 열려 있습니다.

ComfyUI 그래프에 `LoadImage`가 있으면 **그 파일명을 미리 읽어 빈 자리로 만들어 둡니다.** 어떤
파일을 썼는지 이름으로 남아 있으니, 그 자리에 실제 이미지를 끌어다 놓으면 이름은 그대로 두고
그림만 채워집니다.

### input 폴더 연결 (자동 채우기)

그 파일들은 보통 ComfyUI의 `input/` 폴더에 그대로 있습니다. 헤더의 **🔗 input 폴더** 를 눌러
한 번 연결해두면 빈 자리가 **자동으로 채워집니다.** 연결 시점에 기존 항목 전체를 훑고, 이후
새로 들어오는 항목은 스캔하면서 같이 채웁니다.

- 찾은 파일은 `.refs/`로 **복사**합니다. 나중에 `input/`을 비워도 기록은 남습니다.
- `clipspace/pasted.png [input]` 처럼 하위 폴더나 타입 접미사가 붙은 이름도 해석합니다.
- 한글 파일명은 유니코드 정규화(NFC/NFD)가 달라도 찾아냅니다.
- 못 찾은 이름은 빈 자리로 남겨둡니다. 직접 끌어다 놓으면 됩니다.
- 읽기 권한만 사용하며, 브라우저 특성상 세션마다 한 번 다시 눌러 허용해야 합니다
  (연결됐지만 권한이 없으면 버튼이 🔒 로 표시됩니다).

실측: 출력 PNG 1,200장에서 나온 참조 파일명 54개 중 52개가 `input/`에 실제로 존재했습니다.

내보내기에는 참조가 320px로 줄여 함께 들어갑니다(영상은 정지컷, 오디오는 파일명 칩).
첨부하지 않은 자리는 파일명만 남습니다.

## 데이터 안전

- `metadata.json` 파싱에 실패하면 **덮어쓰지 않고 멈춥니다.** 손상본은
  `metadata.corrupt-<날짜>.json` 으로 격리되고, 세션 시작 시 마지막 정상본이
  `metadata.backup.json` 으로 보관됩니다.
- 저장은 임시 파일에 쓴 뒤 교체하며, 동시 저장은 직렬화되어 서로 섞이지 않습니다.

## 단축키

| 키 | 동작 |
|---|---|
| `/` | 검색창 포커스 |
| `Esc` | 모달 닫기 |

드래그앤드롭으로 파일을 추가할 수 있습니다.

## 알려진 제약

- 파일명과 수정시각이 동시에 바뀌면 옮긴 파일로 인식하지 못하고 새 항목이 됩니다
  (내용 해시 기반 매칭은 아직 없습니다)
- 카드 목록에 가상 스크롤이 없어 수천 장에서는 필터·검색 시 렌더가 무거워집니다
- 영상에는 표준 메타데이터가 없어 프롬프트를 직접 입력해야 합니다
